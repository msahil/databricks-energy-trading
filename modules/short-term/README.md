## Run order

Notebook **01** owns the shared dimensions (`short_term_dim_zones`, `short_term_dim_assets`, `short_term_dim_intervals`) and near-delivery gold tables. Notebook **03** (DSR) depends on 01. Notebook **02** (control tower) aggregates 01 + 03, so it runs **before** notebook **04** (Genie).

```text
01 ─┬─► 03 ─┐
    └───────┴─► 02 ─► 04
```

Job task keys: `st01_trading_near_delivery` → `st03_dsr_market_access` → `st02_operations_live_dispatch` → `st04_trader_insights`.

## Unity Catalog target

All tables are written to `energy_utilities.energy_trading2` by default (same schema as long-term; `short_term_*` prefix). Override per-run via widgets `catalog` and `schema`, or via `DEMO_UC_CATALOG` / `DEMO_UC_SCHEMA`.

## Streaming vs batch in the demo

`main.md` frames the desk as sub-second streaming (Structured Streaming Real-Time Mode, Lakeflow DLT). Notebooks **materialise the same gold tables in batch** over a fixed 15-minute interval grid, carrying `snapshot_ts` / `forecast_ts` so Dash pages can show “as last updated”. App pages consume gold tables identically either way.
